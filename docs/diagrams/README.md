# Diagrams

This directory should contain exported Sigasi diagrams documenting
the processor's RTL architecture, module hierarchy and signal
connectivity.

## Contribution Guidelines

- Export diagrams from Sigasi in SVG format.
- Export diagrams once a module/subsystem has been
  implemented and verified, before submitting its pull request.
- Include the exported diagrams in the corresponding pull request.
- Reference these diagrams in the relevant module or architecture
  documentation.
- Regenerate affected diagrams whenever subsequent RTL changes
  alter the hardware structure or connectivity.
